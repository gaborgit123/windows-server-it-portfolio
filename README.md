# Windows Server és hálózatüzemeltetési laborfeladatok

**Dósa Gábor | informatikai rendszer- és alkalmazásüzemeltető technikus tanuló**

Ebben a portfólióban az iskolai Windows Server és hálózati laborfeladataimhoz készített dokumentációkat mutatom be. A feladatokat virtuális, oktatási környezetben végeztem, önállóan és tananyag, illetve saját jegyzetek felhasználásával. A dokumentációk a konfigurálás lépéseit és képernyőképeket tartalmaznak; nem éles vállalati rendszereket mutatnak be.

## Dokumentációk

- [01 Windows Server es kliens](01_Windows_Server_es_kliens.pdf) — Windows Server és Windows kliens telepítése VirtualBoxban; alapbeállítások és szerverfunkciók.
- [02 AD DNS DHCP](02_AD_DNS_DHCP.pdf) — Active Directory, DNS és DHCP szerepkörök telepítése és laborbeállításai.
- [03 Csoporthazirend GPO](03_Csoporthazirend_GPO.pdf) — OU-k, csoportházirendek, mappák és parancsikonok beállítása.
- [04 Tavoli asztal RDP](04_Tavoli_asztal_RDP.pdf) — Távoli asztali hozzáférés és bejelentkezési jogosultságok gyakorlati beállítása.

## Használt technológiák

Windows Server 2019, Windows 10, Oracle VirtualBox, Active Directory Domain Services, DNS, DHCP, Group Policy, Remote Desktop Protocol (RDP).

## Megjegyzések

Az anyagok tanulási és portfóliócélúak. Az egyes beállítások az adott laborhálózathoz igazodnak, nem általános vállalati üzemeltetési ajánlások.
